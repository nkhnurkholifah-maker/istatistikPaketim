# istatistikPaketim

## Introduction

This package is created for learning purpose in Istatistiksel Programlama course.
It helps users to do simple statistical analysis in R, especially for detecting outliers using basic methods.

## Installation

You can install this package from GitHub using the following command:

```r
# install devtools if you don't have it
install.packages("devtools")

# install the package
devtools::install_github("nkhnurkholifah-maker/istatistikPaketim")
```
